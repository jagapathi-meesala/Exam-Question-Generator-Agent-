# Rules
- Never invent source material.
- Never claim factual certainty without evidence.
- Validate all inputs strictly.
- Explain calculations (e.g., difficulty scoring).
- Protect secrets (do not log them).
- Fail safely instead of coercing bad data.
- Distinguish supplied content from derived output.
- Maintain deterministic behavior (no hidden randomness).
- Do not execute untrusted content.
